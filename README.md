# LLM Chat

This is just another LLM web UI, specifically built for how I like it—keeping just Ollama in focus. I used to use a particular LLM UI before, which I liked so much mainly because you could edit any message anywhere in the conversation (both your chats and LLM chats). It felt as if nothing happened, and the next time you sent to the API, it would go with the new context. I don't think this was available in such an intuitive and simple way in any of the other available UIs. Unfortunately, that software had some bugs and underwent some design decisions that I thought were more on the malicious side, so I can't use it anymore (obscuring download of older versions is one of them).

This is a completely vibe-coded project. I wanted to try vibe coding myself, so I built this using the GPT-4 models available in VS Code Agent mode. Manual interventions are minimal and this is an unfinished project—I stopped when I felt like I was getting more comfortable writing it myself than making it write it. I'm keeping this project on GitHub just to keep the records (and, secretly, because I want to delete some files from my system... I'm probably never going to complete this ever).

From requirements.txt, .gitignore, this README, to uploading it to github everything is done by it—I swear I didn't do anything myself. Now I will go learn some Rust. Bye...
